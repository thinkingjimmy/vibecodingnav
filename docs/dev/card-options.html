首页场景卡片 · 四个方向

同一份数据：做 Web 前端，按综合分（方法 C）取前 5。卡片宽度按首页 3 列（约 378px）。标题下不再列基准名。

A分数 + 细条 + 覆盖点

优 一眼看到分数与差距，四个点说明“上了几张榜”。
缺 每行三种元素，信息密度最高。

B只留分数，悬停看各榜

优 最安静，和其他单榜卡片完全一致。
缺 覆盖信息藏在悬停里，触屏上看不到。

C榜首突出 + 一句理由

优 直接给结论，像编辑推荐。
缺 第 1 名占一半高度；2–4 名只差 2 分，突出 1 名会夸大差距以外的确定性。

D分段条：各榜贡献

优 把“综合”怎么来的画出来，缺榜（斜线）一目了然。
缺 需要图例；四种灰阶在小尺寸下难分，像图表不像列表。

首页语境 · 方案 A

四张场景卡片。单榜场景的覆盖点只有一个，直接隐藏。
