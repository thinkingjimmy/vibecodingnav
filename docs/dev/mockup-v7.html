Phosphor Icons

库

为界面设计的统一图标家族：1,248 个图标、6 种字重，按 16×16 网格绘制，小尺寸也清楚。换风格只改一个 weight 属性。

MIT · phosphoricons.com · github.com/phosphor-icons · @phosphor-icons/react 2.1.10 · Web / React / Vue / Flutter / Elm

安装与用法

为什么选，什么时候别用

为什么选　同一套图标覆盖细线到填充六种风格，界面换调性不用换图标库；支持 tree-shaking，只打包用到的图标。

别用　需要 OpenAI、Anthropic 等 AI 品牌 logo 时，用 LobeHub Icons；项目已经用 shadcn/ui 默认的 Lucide 且没有字重需求，不必换。

注意　开发模式下从主入口导入，部分打包器会编译全部 9,000+ 个模块，拖慢启动；可按路径单独导入（官方 README 说明）。

    选不选它

    为什么选
    • Terminal-Bench、LMArena WebDev、Android Bench 长程任务三项第一，覆盖终端、前端、移动端。
    • Terminal-Bench 领先第二名 Sonnet 5.5 三个百分点（64.8% vs 61.8%），单次跑分成本更低（$4.7k vs $7.3k）。
    什么时候别选
    • 批量或 CI 任务：GPT-6.1 Sol 在 Terminal-Bench 拿到 58.2%，成本 $0.6k，约为它的八分之一。
    • 只做前端：Claude Sonnet 5.5 WebDev 1774 分，价格只有一半（$2 / $10）。
    • 对延迟敏感：Android Bench 长程任务平均耗时 15.2 小时。
