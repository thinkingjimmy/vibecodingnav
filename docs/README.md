# docs/

项目文档目录：当前开发状态、视觉验收记录与历史归档，统一收纳于此。本目录不使用 GEB 分形文档系统，文件无需 L1/L2/L3 契约或 `[PROTOCOL]` 标记。

## 结构

- CURRENT.md: 当前开发单一真相源，记录已实现能力、数据流、验证命令、已知边界与优先事项。
- design-qa.md: 当前视觉标注的文字验收结论，不收纳截图资产。
- archive/: 历史需求、设计基线与阶段执行记录；可包含已完成和未完成项目，但不冒充现状。

## 约定

- 实现或优先级变化时更新 `CURRENT.md`；按日期形成的方案稿归档进 `archive/`，不要堆在 docs/ 顶层。
- 当前状态以 `CURRENT.md` 为准；从 `archive/` 恢复任务时，先把可执行结论同步到 `CURRENT.md`。

法则: 当前事实·历史分离·可追溯
